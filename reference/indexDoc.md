# Helper for consistent documentation of `index` argument

Helper for consistent documentation of `index` argument

## Arguments

- index:

  A choice between the different indexes: `"body_mass_index"`,
  `"charlson"`, `"electronic_frailty_index"`,
  `"electronic_frailty_index_2"`, `"hospital_frailty_risk_score"`, and
  `"updated_charlson"`.
